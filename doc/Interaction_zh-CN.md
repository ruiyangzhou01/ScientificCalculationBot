# 聊天互动与群聊管理

[TOC]

[English](Interaction.md) | [简体中文](Interaction_zh-CN.md) | [Deutsch](Interaction_de.md) | [Español](Interaction_es.md) | [Français](Interaction_fr.md)

## 概览

本文档汇总机器人使用的聊天互动与群聊管理接口，接口来自 CoolQ HTTP API 插件。如需完整说明，请参考插件官方文档。

## API

### 基础互动

#### `send_private_msg` 发送私聊消息

##### 参数

| 字段名        | 数据类型 | 默认值  | 说明                                                         |
| ------------- | -------- | ------- | ------------------------------------------------------------ |
| `user_id`     | number   | -       | 对方 QQ 号                                                   |
| `message`     | message  | -       | 要发送的内容                                                 |
| `auto_escape` | boolean  | `false` | 消息内容是否作为纯文本发送（即不解析 CQ 码），仅在 `message` 为字符串时有效 |

##### 响应

| 字段名       | 数据类型       | 说明    |
| ------------ | -------------- | ------- |
| `message_id` | number (int32) | 消息 ID |

#### `send_group_msg` 发送群消息

##### 参数

| 字段名        | 数据类型 | 默认值  | 说明                                                         |
| ------------- | -------- | ------- | ------------------------------------------------------------ |
| `group_id`    | number   | -       | 群号                                                         |
| `message`     | message  | -       | 要发送的内容                                                 |
| `auto_escape` | boolean  | `false` | 消息内容是否作为纯文本发送（即不解析 CQ 码），仅在 `message` 为字符串时有效 |

##### 响应

| 字段名       | 数据类型       | 说明    |
| ------------ | -------------- | ------- |
| `message_id` | number (int32) | 消息 ID |

#### `send_discuss_msg` 发送讨论组消息

##### 参数

| 字段名        | 数据类型 | 默认值  | 说明                                                         |
| ------------- | -------- | ------- | ------------------------------------------------------------ |
| `discuss_id`  | number   | -       | 讨论组 ID（通常不可见，需要从讨论组消息事件中获取）           |
| `message`     | message  | -       | 要发送的内容                                                 |
| `auto_escape` | boolean  | `false` | 消息内容是否作为纯文本发送（即不解析 CQ 码），仅在 `message` 为字符串时有效 |

##### 响应

| 字段名       | 数据类型       | 说明    |
| ------------ | -------------- | ------- |
| `message_id` | number (int32) | 消息 ID |

#### `send_msg` 发送消息

##### 参数

| 字段名         | 数据类型 | 默认值  | 说明                                                         |
| -------------- | -------- | ------- | ------------------------------------------------------------ |
| `message_type` | string   | -       | 消息类型：`private`、`group`、`discuss`。若不填则根据 `*_id` 判断 |
| `user_id`      | number   | -       | 对方 QQ 号（`message_type` 为 `private` 时需要）             |
| `group_id`     | number   | -       | 群号（`message_type` 为 `group` 时需要）                      |
| `discuss_id`   | number   | -       | 讨论组 ID（`message_type` 为 `discuss` 时需要）               |
| `message`      | message  | -       | 要发送的内容                                                 |
| `auto_escape`  | boolean  | `false` | 消息内容是否作为纯文本发送（即不解析 CQ 码），仅在 `message` 为字符串时有效 |

##### 响应

| 字段名       | 数据类型       | 说明    |
| ------------ | -------------- | ------- |
| `message_id` | number (int32) | 消息 ID |

#### `delete_msg` 撤回消息

##### 参数

| 字段名       | 数据类型       | 默认值 | 说明    |
| ------------ | -------------- | ------ | ------- |
| `message_id` | number (int32) | -      | 消息 ID |

##### 响应

无。

#### `send_like` 发送好友赞

##### 参数

| 字段名    | 数据类型 | 默认值 | 说明                             |
| --------- | -------- | ------ | -------------------------------- |
| `user_id` | number   | -      | 对方 QQ 号                       |
| `times`   | number   | 1      | 赞的次数，每个好友每天最多 10 次 |

##### 响应

无。

### 群聊管理

#### `set_group_kick` 群组踢人

##### 参数

| 字段名               | 数据类型 | 默认值  | 说明               |
| -------------------- | -------- | ------- | ------------------ |
| `group_id`           | number   | -       | 群号               |
| `user_id`            | number   | -       | 要踢的 QQ 号       |
| `reject_add_request` | boolean  | `false` | 拒绝此人的加群请求 |

##### 响应

无。

#### `set_group_ban` 群组单人禁言

##### 参数

| 字段名     | 数据类型 | 默认值    | 说明                             |
| ---------- | -------- | --------- | -------------------------------- |
| `group_id` | number   | -         | 群号                             |
| `user_id`  | number   | -         | 要禁言的 QQ 号                   |
| `duration` | number   | `30 * 60` | 禁言时长，单位秒，0 表示取消禁言 |

##### 响应

无。

#### `set_group_anonymous_ban` 群组匿名禁言

##### 参数

| 字段名                      | 数据类型 | 默认值    | 说明                                                        |
| --------------------------- | -------- | --------- | ----------------------------------------------------------- |
| `group_id`                  | number   | -         | 群号                                                        |
| `anonymous`                 | object   | -         | 可选，匿名用户对象（来自群消息事件）                        |
| `anonymous_flag` 或 `flag`  | string   | -         | 可选，匿名用户的 flag（来自群消息事件）                     |
| `duration`                  | number   | `30 * 60` | 禁言时长，单位秒，匿名禁言无法取消                          |

`anonymous` 与 `anonymous_flag` 二选一即可，若同时传入则使用 `anonymous`。

##### 响应

无。

#### `get_record` 获取语音

该接口会把语音转换为指定格式并返回文件名（位于 `data\record` 目录）。**使用该接口需安装 酷Q 的 [语音组件](https://cqp.cc/t/21132)。**

##### 参数

| 字段名       | 数据类型 | 默认值  | 说明                                                         |
| ------------ | -------- | ------- | ------------------------------------------------------------ |
| `file`       | string   | -       | 收到的语音文件名（CQ 码 `file` 参数），如 `0B38145AA44505000B38145AA4450500.silk` |
| `out_format` | string   | -       | 转换格式：`mp3`、`amr`、`wma`、`m4a`、`spx`、`ogg`、`wav`、`flac` |
| `full_path`  | boolean  | `false` | 是否返回绝对路径（Windows 环境建议开启，Docker 不建议）       |

##### 响应

| 字段名 | 数据类型 | 说明                                                         |
| ------ | -------- | ------------------------------------------------------------ |
| `file` | string   | 转换后的语音文件名或路径，如 `0B38145AA44505000B38145AA4450500.mp3`（`full_path` 为 `true` 时返回完整路径） |

#### `get_status` 获取插件运行状态

##### 参数

无。

##### 响应

| 字段名            | 数据类型 | 说明                                                         |
| ----------------- | -------- | ------------------------------------------------------------ |
| `app_initialized` | boolean  | HTTP API 插件已初始化                                        |
| `app_enabled`     | boolean  | HTTP API 插件已启用                                          |
| `plugins_good`    | object   | HTTP API 的各内部插件是否正常运行                            |
| `app_good`        | boolean  | 插件正常运行（已初始化、已启用、各内部插件正常运行）         |
| `online`          | boolean  | 当前 QQ 在线状态（`null` 表示无法检测）                      |
| `good`            | boolean  | 插件状态符合预期                                             |

通常建议只关注 `online` 与 `good` 两个字段，其余字段可能随插件更新而变化。

`online` 字段可通过 `online_status_detection_method` 切换检测方式：

| 在线检测方式                | 优点                                                         | 缺点                                                         |
| --------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `get_stranger_info`（默认） | 正常情况下比 `log_db` 更准确；需要网络请求                    | 请求频率过高时可能不准确                                     |
| `log_db`                    | 查询速度快；无需网络请求（避免腾讯风控）                      | 可能因酷Q修改数据库结构而失效；月末掉线、月初检测不到         |

| `delay` | number   | `0`    | 延迟的毫秒数，若默认无法重启可尝试 2000 左右                   |

##### 响应

无。
