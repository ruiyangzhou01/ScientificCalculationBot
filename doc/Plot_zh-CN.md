## 概览

本模块基于 Python 的 matplotlib 库，通过 QQ 消息输入绘图指令，并以图片消息返回绘制结果。

## 指令模板

```python
function('p1', 'p2')
```

- 每个参数都需要用单引号包裹。

## 功能

### `draw` 一元显函数

绘制并输出一元显函数曲线。

##### 参数

| 参数      | 数据类型 | 默认值 | 说明                     |
| --------- | -------- | ------ | ------------------------ |
| `fun`     | 字符串   | -      | 显函数表达式             |
| `x_range` | 字符串   | -      | 变量起始值、终值与步长   |

##### 注意

- 变量范围的三个子参数用英文逗号分隔。

##### 示例

```python
# draw(fun, x_range)
draw('sin(x) / x', '-10, 10, 0.1')
```

### `draw_imp` 隐函数

绘制并输出二元隐函数曲线。

##### 参数

| 参数       | 数据类型 | 默认值 | 说明                   |
| ---------- | -------- | ------ | ---------------------- |
| `equation` | 字符串   | -      | x、y 的隐函数表达式    |
| `x_range`  | 字符串   | -      | x 的起始值与终值       |
| `y_range`  | 字符串   | -      | y 的起始值与终值       |

##### 注意

- 变量范围的起始值与终值用英文逗号分隔。

##### 示例

```python
# draw_imp(equation, x_range, y_range)
draw_imp('17 * x**2 - 16*abs(x)*y + 17 * y**2 - 256', '-6, 6', '-6, 6')
```

### `draw_para` 参数方程

绘制并输出单参数的参数方程曲线。

##### 参数

| 参数     | 数据类型 | 默认值 | 说明                           |
| -------- | -------- | ------ | ------------------------------ |
| `x_eq`   | 字符串   | -      | x 关于 t 的方程                |
| `y_eq`   | 字符串   | -      | y 关于 t 的方程                |
| `t_range`| 字符串   | -      | t 的起始值、终值与步长         |

##### 注意

- 变量范围的参数用英文逗号分隔。

##### 示例

```python
# draw_para(x_eq, y_eq, t_range)
draw_para('2*sin(t)', '3*cos(t)', '0, 2*pi, 0.1')
```
